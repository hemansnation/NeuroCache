# Contributing to NeuroCache

First of all, thank you for taking the time to contribute to NeuroCache 🎉  
Contributions from the community help make this project better, more reliable, and more useful for everyone.

## Ways to Contribute

You can contribute to NeuroCache in many ways, including:

- Reporting bugs
- Suggesting new features or improvements
- Improving documentation
- Writing or improving tests
- Submitting code changes via pull requests

## Getting Started

1. Fork the repository on GitHub
2. Clone your fork locally
3. Create a new branch for your work
4. Make your changes
5. Test your changes thoroughly
6. Commit and push your branch
7. Open a Pull Request

## Branch Naming Convention

Use descriptive branch names such as:

- feature/add-memory-filtering
- bugfix/fix-retrieval-error
- docs/improve-readme

## Coding Guidelines

- Follow Python best practices (PEP 8)
- Write clean, readable, and maintainable code
- Add docstrings and comments where necessary
- Avoid unnecessary dependencies
- Keep changes focused and minimal

## Commit Messages

Write clear and meaningful commit messages:

- Good: `Add local cache eviction strategy`
- Bad: `Fix stuff`

## Pull Request Guidelines

When opening a Pull Request:

- Clearly describe what the PR does
- Reference related issues if applicable
- Include screenshots or logs if relevant
- Ensure existing tests pass
- Be open to feedback and requested changes

## Reporting Bugs

If you find a bug, please open an issue and include:

- A clear description of the problem
- Steps to reproduce the issue
- Expected vs actual behavior
- Environment details (OS, Python version)

## Feature Requests

Feature requests are welcome. Please explain:

- The problem you are trying to solve
- Why this feature is useful
- Any alternative solutions considered

## Community Expectations

Please be respectful, inclusive, and constructive when contributing.  
All contributors are expected to follow the Code of Conduct.

By contributing to this project, you agree that your contributions will be licensed under the MIT License.

Thank you for helping improve NeuroCache 🚀
